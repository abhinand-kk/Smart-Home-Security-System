About This Project

Overview of the technology and components planned for this IoT system

ESP32 Microcontroller

A versatile Wi-Fi enabled microcontroller board that reads digital signals from the motion sensor and sends data over local Wi-Fi.

PIR Motion Sensor

A Passive Infrared (HC-SR501) sensor that senses changes in infrared radiation emitted by moving people or warm bodies within its field of view.

Python Backend (Planned)

A future web API server created with Python (such as Flask) that receives HTTP requests from the ESP32 and provides data to this website.

Motion History Database (Planned)

A structured database (such as SQLite) to securely store timestamped motion events for historical tracking and review.
